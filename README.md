# -Bank-Credit-Prediction-ML-Algorithms-Comparison#

### A Machine Learning project to predict credit approval and compare the performance of various algorithms.

## 📌 Project Overview
In the banking sector, determining whether a customer is eligible for a credit loan is a critical decision. This project aims to automate and optimize this process by predicting credit approvals based on customers' financial and demographic data. 

As a collaborative team project, we analyzed a dataset from Kaggle and implemented both supervised and unsupervised learning models to find the most accurate prediction algorithm.

## 🧠 Machine Learning Models Used
We trained and compared the following four algorithms to evaluate their performance:
1. **Decision Tree** (Supervised Learning)
2. **Random Forest** (Ensemble Learning)
3. **Artificial Neural Networks - ANN** (Deep Learning)
4. **K-Means** (Unsupervised Learning / Clustering)

## 📊 Dataset & Features
The dataset used includes various customer attributes such as:
- **Age:** Customer's age.
- **Monthly Income:** Regular income of the customer.
- **Debt Status:** Current financial obligations.
*(The dataset was sourced from Kaggle and preprocessed for optimal model training).*

## 🏆 Results & Evaluation
We evaluated the models based on metrics like Accuracy, Precision, Recall, F1-Score, and ROC-AUC.
- **Random Forest & Decision Tree** achieved the highest accuracy and performance.
- We visualized the results using **ROC Curves** and bar charts to clearly demonstrate the final success rates of each model.

## 🛠️ Tech Stack & Tools
- **Language:** Python
- **Libraries:** Scikit-Learn, Pandas, NumPy, Matplotlib, Seaborn
- **Concepts:** Data Preprocessing, Classification, Deep Learning, Algorithm Evaluation.
